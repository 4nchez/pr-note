# PR노트 (PR Note)

인터넷 연결 없이 동작하는 개인용 근력운동 기록 웹앱입니다. 삼성 메모장에 손으로 적던 운동 기록을, 세트별로 입력하고 이전 기록과 자동으로 비교해주는 형태로 옮기기 위해 만들었습니다.

설치도, 서버도, 회원가입도 없습니다. `index.html` 파일 하나가 앱의 전부입니다.

## 특징

- **오프라인 우선** — 모든 데이터는 브라우저의 로컬 저장소(`localStorage`)에만 저장됩니다. 인터넷 연결이 없어도 100% 동작하고, 어떤 데이터도 외부 서버로 전송되지 않습니다.
- **기록하면 바로 비교** — 세트를 저장하면 지난 기록 대비 총 볼륨·최고 중량·추정 1RM이 얼마나 늘었는지 알림 배너로 바로 보여줍니다. 신기록을 세우면 PR 게이지가 채워집니다.
- **근력운동 중심** — 바벨/덤벨/머신 운동은 물론 맨몸운동(푸시업, 풀업, 스쿼트 점프 등)까지 기본 종목으로 제공하고, 종목을 자유롭게 추가·수정·삭제할 수 있습니다.
- **운동별 히스토리** — 운동을 골라 세션 수, 최고 기록, 볼륨 추이 그래프를 확인할 수 있고, 최근 4주 / 3개월 / 6개월 / 전체로 기간을 좁혀볼 수 있습니다.
- **백업/복원** — 설정 화면에서 전체 기록을 JSON 파일로 내보내고, 다시 불러올 수 있습니다.

## 시작하기

빌드나 설치 과정이 없습니다.

1. `index.html`을 다운로드합니다.
2. 브라우저로 엽니다 (더블클릭, 또는 모바일에서 "홈 화면에 추가"로 앱처럼 사용 가능).
3. 바로 기록을 시작하면 됩니다.

기능을 먼저 둘러보고 싶다면 `sample-data.json`을 설정 → **기록 가져오기**로 불러오면, 8주치 예시 운동 기록으로 히스토리·그래프·통계 기능을 바로 확인할 수 있습니다.

## 데이터 & 개인정보

- 데이터는 그 브라우저(그 기기)의 로컬 저장소에만 남습니다. 클라우드 동기화는 없습니다.
- 브라우저 데이터를 지우거나 기기를 바꾸면 기록이 사라질 수 있으니, 설정 → **기록 내보내기**로 주기적인 백업을 권장합니다.
- 내보낸 백업 파일은 설정 → **기록 가져오기**에서 "덮어쓰기" 또는 "기존 데이터에 합치기"로 복원할 수 있습니다.

## 기술 스택

- Vanilla HTML / CSS / JavaScript — 프레임워크, 외부 라이브러리, 빌드 도구 없음
- 단일 파일 구조로 어디서든(로컬, USB, GitHub Pages 등) 그대로 열어서 쓸 수 있습니다
